# Problem brief

- **Problem:** Late deliveries hurt customer reviews and repeat purchases, and operations cannot see which sellers, regions or categories cause them.
- **Stakeholder:** Logistics / marketplace operations manager.
- **Decision:** Which sellers or regions to coach, penalize or reroute.
- **Metrics:** On-time rate; average delay days; review-score drop when an order is late.
- **Data:** Olist Brazilian E-Commerce Public Dataset (9 CSVs).
- **Limits:** Proxy dataset from one marketplace; findings are illustrative, not company data.
